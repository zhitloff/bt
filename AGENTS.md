# Инструкции для работы с проектом

## Обзор

Bt — многомодульная Java-библиотека и BitTorrent-клиент. Проект использует Maven и рассчитан на Java 25. Корневой `pom.xml` задаёт модули, общие зависимости и настройки сборки.

Основные модули:

- `bt-core` — ядро клиента: торренты, сетевой обмен, хранение данных и клиентский API.
- `bt-bencoding` — чтение и запись Bencode, используемого в метаданных BitTorrent.
- `bt-dht` — поддержка DHT.
- `bt-http-tracker-client` — клиент HTTP-трекеров.
- `bt-upnp` — интеграция с UPnP для перенаправления портов.
- `bt-tests` — общие и интеграционные тесты.
- `bt-cli` — консольный клиент.
- `examples` — примеры использования.
- `jacoco-report` — отчёты о покрытии.

## Сборка и тесты

Запускайте команды Maven из корня репозитория:

```bash
mvn test
```

Для установки модулей в локальный Maven-репозиторий без запуска тестов:

```bash
mvn clean install -DskipTests
```

При необходимости ограничивайте проверку изменённым модулем, например:

```bash
mvn -pl bt-bencoding test
```

Если тесты или сборка не проходят, разберитесь, связано ли это с изменениями или с окружением; сообщайте о непроверенных сценариях явно.

## Правила изменений

- Поддерживайте целевую платформу Java 25; используйте настройки `maven.compiler.release` из корневого POM.
- Следуйте существующему Maven-разбиению: размещайте реализацию и тесты в соответствующих модулях, не добавляя зависимости между модулями без необходимости.
- Поддерживайте стиль соседнего кода и используйте существующие библиотеки и абстракции проекта вместо дублирования функциональности.
- Для исправления поведения добавляйте или обновляйте тесты рядом с соответствующим модулем. Не меняйте тесты лишь для обхода ошибки реализации.
- Избегайте несвязанных изменений, массового форматирования и обновления версий зависимостей, если этого не требует задача.
- Перед завершением проверьте diff и запустите подходящие тесты.

## Важные особенности

- CLI расположен в модуле `bt-cli`; его README содержит параметры запуска и примеры для `.torrent` и magnet-ссылок.
- Java 25 включает неограниченную криптографическую политику по умолчанию; отдельная установка JCE для MSE не требуется.
- В README `bt-cli` отдельно отмечено ограничение на распространение бинарной сборки из-за включённых LGPL-зависимостей Lanterna. Не меняйте лицензионные сведения и правила упаковки без явного основания.
